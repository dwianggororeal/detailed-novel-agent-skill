# World Rules Creation Index (Universal Mechanics & Society Framework)

This directory contains the complete framework, templates, and evaluation systems for designing **World Rules** (Universal Laws & Societal Dynamics), ranging from realistic baselines to full-fledged RPG fantasy universes.

---

## 📚 Documents in this Directory

1. **[WORLD_RULES_FRAMEWORK.md](./WORLD_RULES_FRAMEWORK.md)**
   - **Initial Gate Protocol:** User confirmation prompt on world realism baselines (Full Real-Life, Semi-Real + Fiction, or Full Fictional RPG).
   - **Generic RPG Universe Architecture:** 6 core pillars (Races & Social Tensions, Biological Mana & Storage Batteries, 3 Class Archetypes & S1-Equivalent Certification, Guild Labor Market Economics, and Monster Threat Matrices).

2. **[WORLD_RULES_TEMPLATE.md](./WORLD_RULES_TEMPLATE.md)**
   - Master template for recording modular world rules (Racial Anatomy & Frictions, Mana Battery Mechanics, Vanguard/Spellcaster/Striker Archetypes, Guild Certification Exams, and Ecological Classifications).

3. **[WORLD_RULES_EVALUATION.md](./WORLD_RULES_EVALUATION.md)**
   - Evaluation rubric for world logic (4 assessment dimensions).
   - Scorecard and 3 Logic Stress Tests (Labor Oversupply, Mana Battery Exploitation, and Racial Stereotype Nuance Test).
